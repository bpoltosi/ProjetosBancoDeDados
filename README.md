# ProjetosBancoDeDados

Repositório dedicado ao estudo e desenvolvimento de projetos relacionados a **bancos de dados**, reunindo projetos acadêmicos, exercícios, scripts e materiais de referência.

## Objetivos

Este repositório centraliza a evolução prática em:

- modelagem de bancos de dados;
- SQL e consultas;
- Oracle Database / PL-SQL;
- Microsoft SQL Server / T-SQL;
- bancos NoSQL;
- integração entre aplicações e bancos de dados;
- boas práticas de organização, documentação e versionamento.

## Projetos

### Sistema de Gestão de Construção Civil — Oracle

Projeto acadêmico de banco de dados voltado à gestão de construtoras e obras.

O projeto trabalha conceitos como:

- modelagem conceitual e lógica;
- DER e relacionamento entre entidades;
- Oracle Database;
- Oracle SQL;
- PL/SQL;
- DDL;
- DML;
- DQL;
- consultas e análises sobre os dados.

Entre as entidades do domínio estão elementos como **CONSTRUTORA, OBRA, TRABALHADOR e EQUIPAMENTO**, formando um cenário para praticar relacionamentos, integridade e consultas em banco relacional.

[→ Acessar o projeto](./Sistema-Gestao-Construcao-Civil-Oracle/)

## Utils

A pasta [utils](./utils/) contém referências rápidas para estudo e desenvolvimento:

- [SQLutils.md](./utils/SQLutils.md) — SQL geral;
- [T-SQLutils.md](./utils/T-SQLutils.md) — Microsoft SQL Server / T-SQL;
- [NoSQLutils.md](./utils/NoSQLutils.md) — bancos NoSQL.

Esses documentos são mantidos como materiais de consulta e podem evoluir junto com os projetos do repositório.

## Tecnologias e conceitos

| Área | Tecnologias / conceitos |
|---|---|
| Relacional | Oracle Database, SQL Server, SQL |
| Oracle | SQL, PL/SQL, Oracle Live SQL |
| SQL Server | T-SQL |
| NoSQL | MongoDB, Redis/Valkey, Cassandra, Neo4j |
| Modelagem | DER, modelo conceitual e modelo lógico |

## Organização e evolução

Novos projetos podem ser adicionados conforme o avanço acadêmico e profissional, mantendo cada projeto com sua própria documentação e estrutura.

A pasta `utils` funciona como uma base compartilhada de consulta, enquanto os diretórios de projetos concentram implementações, scripts e materiais específicos de cada sistema.
